CASSINI Hackathon Project

Resilient Navigation for Critical Infrastructure Under GNSS Spoofing

A dual-layer offline navigation system designed for emergency vehicles. It detects signal manipulation in real-time and transitions to visual landmark recognition when satellite data fails.

Download APK & Demo

How It Works

A seamless multi-stage pipeline bridging satellite reconnaissance and edge Android processing.

01 / PRE-TRIP

Laptop Data Preparation

Aggregating Copernicus EMS satellite layers and filtering threat zones via automated text analytics before deployment.

02 / PACKAGING

Offline Route Package

Compiling localized GeoJSON maps, road networks, and verified visual landmark databases into a lightweight standalone package.

03 / ON-BOARD

Android Core & CameraX

Real-time telemetry monitoring of Galileo constellations, spoofing detection, and OpenCV-based visual tracking.

Space-Enabled Intelligence

Leveraging European space infrastructure for absolute operational awareness.

Galileo Constellation Monitoring

Continuous tracking of European Galileo satellite signals via `GnssStatus`. Evaluating active fixes and monitoring signal integrity to instantly flag spoofing anomalies.

Copernicus EMS Integration

Utilizing pre-trip satellite imagery layers of crisis zones to automatically exclude compromised roads and route emergency teams safely.

Prototype Demonstration

Test builds, documentation, and visual proof of concept.

Roadmap & Prototype Limitations

Transparent overview of current 48-hour hackathon scope vs. future production rollout.

Hackathon Scope (Current 48H)

Standalone offline Android APK, static routing packages for pre-tested urban zones, bench-tested camera recognition via OpenCV, and simulated GNSS fault injections.

Phase 2: Live Cloud Integration

Automated backend server deployment for continuous LLM news parsing and dynamic route updates without manual pre-packaging.

Phase 3: Fleet Deployment

Integration with vehicle OBD sensors, hardware-level cryptographic OSNMA validation, and large-scale field tests with emergency services.
